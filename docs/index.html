How it works

  1. Agent ID is the gate. The contracts call balanceOf() on the official Agent ID contract (0x60B9…022F) — only holders can check in.
  2. Names resolve on-chain. Tips call ownerOfHandle() on the same contract. Unknown names revert and no funds move.
  3. Badges are soulbound. 7 / 30 / 100-day streaks mint a non-transferable badge NFT, like the Agent ID itself.
  4. Nothing is held. Tips forward in the same transaction. The contracts never hold your BNB and take no fee.

Contracts: AgentIDHub · StreakBadge — source verified on BscScan. Owner powers: pause/unpause only. No upgrades, no fund movement, no token.
